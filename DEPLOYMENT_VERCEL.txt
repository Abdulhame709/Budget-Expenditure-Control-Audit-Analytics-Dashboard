# Vercel deployment guide for Budget & Audit Analytics System
# ====================================================================

## 🚀 Quick Start

### 1. Go to Vercel and connect GitHub
- Visit: https://vercel.com
- Sign in with your **GitHub** account
- Click **"Add New Project"**

### 2. Import Repository
- Find: **Budget-Expenditure-Control-Audit-Analytics-Dashboard**
- Click **"Import"**
- Vercel will automatically detect it as a Python project

### 3. Configure Build
- **Framework Preset**: Django (auto-detected from the root `manage.py`)
- **Build Command**: leave empty (Vercel's Django builder runs static collection during the build)
- **Output Directory**: leave empty
- **Install Command**: leave empty (Vercel installs the root `requirements.txt`)

Do not run `collectstatic` from `system/vercel_wsgi.py` or any request-time code.
The deployed function filesystem (`/var/task`) is read-only; static assets and
`staticfiles.json` must be generated and packaged during the Vercel build.

### 4. Add Environment Variables
Copy ALL of these to **Settings → Environment Variables**:

```
DJANGO_SETTINGS_MODULE=config.settings.production
DJANGO_ENV=production
DJANGO_SECRET_KEY=[your-generated-secret]
DJANGO_ALLOWED_HOSTS=your-app.vercel.app,localhost,127.0.0.1
DJANGO_SECURE_SSL_REDIRECT=true
DJANGO_SECURE_HSTS_SECONDS=31536000
DJANGO_SECURE_HSTS_INCLUDE_SUBDOMAINS=true
DJANGO_SECURE_HSTS_PRELOAD=true
DJANGO_SECURE_BROWSER_XSS_FILTER=true
DJANGO_SECURE_CONTENT_TYPE_NOSNIFF=true
DJANGO_CSRF_TRUSTED_ORIGINS=https://your-app.vercel.app
DATABASE_URL=postgresql://postgres.doehmumbdoaxppqxhnwt:8abduh772600@aws-0-ap-northeast-2.pooler.supabase.com:5432/postgres
MIGRATION_DATABASE_URL=postgresql://postgres.doehmumbdoaxppqxhnwt:8abduh772600@aws-0-ap-northeast-2.pooler.supabase.com:5432/postgres
ALLOW_SELF_REGISTRATION=False
DJANGO_ALLOW_SYNTHETIC_DATASET=False
PYTHON_VERSION=3.11.2
```

### 5. Deploy
- Click **"Deploy"**
- Wait 2-5 minutes
- You will get a URL like: `https://budget-audit-analytics.vercel.app`

### 6. After Deployment
- Update `DJANGO_ALLOWED_HOSTS` with the actual domain
- Update `DJANGO_CSRF_TRUSTED_ORIGINS` with the actual URL
- Click **"Redeploy"** in Vercel
