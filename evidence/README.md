## التحقق من السلامة (بعد clone من GitHub)

```bash
cd <repo-root>
sha256sum -c evidence/checksums.txt
# النتيجة المتوقعة: OK×7 (صفر خطأ) — الحزمة لا تشير إلى أي ملف مستبعد
```
